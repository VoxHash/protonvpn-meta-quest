# Security

- Only install APKs that pass `scripts/verify-apk.sh` against Proton’s published certificate fingerprint.
- Report packaging vulnerabilities to **contact@voxhash.dev**.
- For Proton VPN product security, follow Proton’s own disclosure process at https://proton.me/security.

Expected certificate SHA-256:

```
DC:C9:43:9E:C1:A6:C6:A8:D0:20:3F:34:23:EE:42:BC:C8:B9:70:62:8E:53:CB:73:A0:39:3F:39:8D:D5:B8:53
```
