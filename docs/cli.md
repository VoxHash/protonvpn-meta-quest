# Scripts (CLI)

| Script | Purpose |
| --- | --- |
| `scripts/download-official-apk.sh` | Fetch latest Proton GitHub APK |
| `scripts/verify-apk.sh` | Check Proton signing certificate |
| `scripts/install-quest.sh` | Verify + install + launch TV UI |
| `scripts/launch-quest.sh` | Start `TvMainActivity` |
| `scripts/e2e-quest.sh` | Device smoke test + artifacts |
| `scripts/fetch-android-app.sh` | Clone upstream Android sources |
| `scripts/apply-quest-patch.sh` | Apply Meta Quest `IsTvCheck` patch |
| `scripts/build-from-source.sh` | Gradle open-source debug APK |
| `scripts/build-quest-launcher.sh` | Build companion launcher |
| `scripts/install-quest-launcher.sh` | Sideload companion launcher |
