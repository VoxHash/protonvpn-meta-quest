# Configuration

| Name | Default | Description |
| --- | --- | --- |
| `QUEST_SERIAL` | auto | ADB serial for the headset |
| `JAVA_HOME` | `~/.local/jvm/jdk-17…` | JDK 17 for Gradle |
| `ANDROID_HOME` | `~/Android/Sdk` | Android SDK |

Proton VPN in-app settings (protocol, Secure Core, NetShield) are unchanged from upstream.
